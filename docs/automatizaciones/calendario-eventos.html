Armalo paso a paso

DESCARGAR WORKFLOW (.JSON)

  1. Importá calendario-eventos.json en n8n (menú de workflows → Import from File). La URL ya apunta a la API del curso: no la cambies.
  2. Conectá el correo. En Enviar calendario por email creá la credencial SMTP (la llave de tu correo, guardada aparte) y reemplazá tu-correo@ejemplo.com y destinatario@ejemplo.com por tu dirección.
  3. Ejecutá a mano (Execute workflow): Eventos de la semana tiene que mostrar hasEvents: true y 4 eventos. Activá el flujo cuando el correo llegue.
04

Cómo se programa: el cron

El horario del primer nodo es una receta de cinco campos: minuto hora día-del-mes mes día-de-la-semana. Un * significa “cualquiera”.

CRONCUÁNDO CORREDÓNDE
0 8 * * 1lunes a las 8:00esta página
0 18 * * 1-5lunes a viernes a las 18:00ejemplo 01
0 17 * * 5viernes a las 17:00ejemplo 03
0 8 * * *todos los días a las 8:00ejemplo 02 (a las 8:00)

La hora es la de la zona horaria configurada en n8n. Para probar un cambio sin esperar al lunes, usá Execute workflow.

05

Hablá con la IA

EL CÓDIGO DEL FILTRO
Escribime el código JavaScript de un nodo Code de n8n en modo "Run Once for All Items" que:
- reciba la respuesta de la API en $input.first().json
- se quede con los eventos de data.events donde days_until sea 7 o menos
- devuelva UN solo item con: hasEvents (boolean), count (cantidad) y texto (el cuerpo del email, con un renglón por evento: fecha, símbolo, nombre y tipo)
- si la respuesta no trae data.events, tire un Error con un mensaje claro en español

Sin librerías externas. Comentá solo lo necesario y decime después cómo probarlo con el caso de cero eventos.
EL HORARIO (CRON)
Quiero que un workflow de n8n corra [DESCRIBÍ CUÁNDO, por ejemplo: el primer día hábil de cada mes a las 9:00].
Dame la expresión cron de cinco campos, explicame campo por campo qué significa y decime las próximas tres fechas en que correría, para comprobarlas a mano. Si no se puede con un solo cron, decime por qué.
