Cómo funciona

1

4

Pedir informe al modelo

ENTRA: hechos · SALE: choices[0].message.content

6

SALE: un correo por semana
03

Armalo paso a paso

DESCARGAR WORKFLOW (.JSON)

  1. Importá informe-semanal-ia.json en n8n. La URL ya apunta a la API del curso: no la cambies.
  2. Creá la credencial del modelo (Header Auth, nombre Authorization, valor Bearer TU_API_KEY) y, en Enviar informe, reemplazá tu-correo@ejemplo.com y destinatario@ejemplo.com por tu dirección.
  3. Ejecutá a mano y compará tres números del correo con la respuesta de la API.
04

Hablá con la IA

EL PROMPT DEL SISTEMA
Necesito el prompt de sistema para un modelo que redacta un informe semanal de mercado a partir de una tabla de datos que le paso en el mensaje del usuario.

Condiciones:
- máximo 120 palabras, un solo párrafo, español rioplatense, tono neutro
- puede usar SOLO los números que aparecen en el texto recibido
- si un dato falta, escribe "sin dato" y sigue
- no da recomendaciones de inversión, no predice precios, no menciona activos que no estén en la tabla
- no repite la tabla: la cuenta

Devolveme: 1) el prompt de sistema listo para copiar, 2) tres casos de prueba con datos incompletos, 3) una lista de las frases que NO debería producir nunca.
AUDITORÍA ANTI-INVENCIÓN
Te paso tres cosas: los datos que le envié al modelo, mi prompt de sistema y el texto que devolvió.

DATOS ENVIADOS:

Hacé una auditoría:
1) marcá cada número, porcentaje, nombre de activo o fecha del texto que NO aparezca en los datos enviados;
2) marcá cada afirmación que sea una recomendación o una predicción;
3) si encontraste algo, reescribí el prompt de sistema agregando la regla mínima que lo impida;
