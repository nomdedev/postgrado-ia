PALABRAS RARAS, EXPLICADAS SIN JERGA

Glosario del taller

Cada vez que en una página aparece una palabra subrayada con puntos, el enlace te trae acá. Las definiciones son cortas a propósito: alcanza con entender para qué sirve cada cosa, no cómo está hecha por dentro.

01

Trabajar con IA

Prompt
El texto con el que le pedís algo a la IA. Cuanto más claro digas qué querés, con qué datos y en qué formato, mejor sale la respuesta.
Prompt de contexto
Un prompt que se pega una sola vez al principio del chat y fija las reglas de todo el proyecto (un solo archivo, datos simulados, español…). Es como la consigna general de un trabajo práctico.
Chat de IA ChatGPT, Claude, Gemini
La ventana donde conversás con el modelo. Recuerda lo que se dijo en ese chat, pero no en otros: si abrís uno nuevo, hay que volver a darle el contexto y el archivo.
Alucinación
Cuando la IA inventa un dato, una función o un resultado con total seguridad. Por eso cada paso del taller tiene una comprobación hecha por una persona.
Versión
Una copia guardada del archivo en un momento en que funcionaba (finlab-v3.html). Si un cambio rompe todo, se vuelve a la última versión buena.
02

La página web

HTML .html
El tipo de archivo de las páginas web. Es texto con etiquetas que el navegador sabe dibujar. Todo el taller produce un solo archivo: finlab.html.
Navegador
Chrome, Edge, Firefox o Safari. Abre el archivo HTML y lo muestra como página.
Consola del navegador F12
Un panel oculto del navegador donde aparecen los errores y los mensajes del código. Se abre con F12 (o clic derecho → Inspeccionar) y la pestaña Console. Si la página queda en blanco, la respuesta casi siempre está ahí, en rojo.
Código
Las instrucciones escritas para la computadora. En este taller no lo escriben ustedes: lo escribe la IA, y ustedes lo prueban y lo verifican.
JavaScript
El lenguaje que hace que una página haga cosas: calcular, responder a clics, dibujar gráficos. Va dentro del HTML.
CDN
Un servidor público desde donde la página descarga herramientas ya hechas (React, Recharts) en lugar de instalarlas. Por eso el archivo funciona sin instalar nada, pero necesita internet la primera vez.
React
Una herramienta para armar interfaces con piezas reutilizables (componentes). La terminal FIN·LAB está hecha con React.
Babel
Un traductor que convierte el código de React a uno que el navegador entiende. Lo cargamos desde el CDN para no tener que instalar nada.
Recharts
Una librería de gráficos para React: líneas, tortas, barras. Es la que dibuja los gráficos de Mercado y Carteras.
Componente
Una pieza de la pantalla con su propia lógica: la tabla, una tarjeta, el gráfico. Se arman por separado y se combinan.
Pestaña
Cada sección de la terminal (Mercado, Carteras…). Al hacer clic se muestra solo esa parte.
#/guiado ruta con numeral
Lo que va después del # en la dirección indica qué pestaña mostrar. #/guiado abre la pestaña EMPEZAR; #/mercado, la de Mercado.
Función
Un bloque de código con nombre que recibe datos y devuelve un resultado, como una fórmula de Excel con nombre propio: sma(precios, 20).
Variable / constante
Un nombre que guarda un valor. RF = 0.043 guarda la tasa libre de riesgo para usarla en varios lugares.
Lista (array)
Una colección ordenada de valores, entre corchetes: [172.4, 173.1, 171.9]. Una serie de precios es una lista.
Objeto
Un conjunto de datos con nombre, entre llaves: { d: '2026-10-26', c: 308.43, v: 51000000 } es un día con fecha, cierre y volumen.
localStorage
Un pequeño espacio de memoria del navegador donde una página puede guardar datos que sobreviven a la recarga (por ejemplo, tus alertas). Vive solo en esa computadora y ese navegador.
03

Datos y archivos

Datos simulados
Números generados por una fórmula que imitan cómo se mueve un precio. No son cotizaciones reales; sirven para aprender porque todos ven lo mismo.
Semilla seed
El número de arranque de un generador de “azar”. Con la misma semilla salen siempre los mismos números, como barajar un mazo siempre de la misma manera.
Rueda
Un día hábil de mercado. Un año tiene unas 252 ruedas (no 365: no se opera fines de semana ni feriados).
Serie de precios
La lista de cierres de un activo, uno por rueda, ordenados por fecha.
Ticker / símbolo
El código corto de un activo: AAPL (Apple), GGAL (Galicia), YPF.
CSV .csv
Una tabla guardada como texto, con los valores separados por comas. Se abre con Excel o Google Sheets y con Python.
JSON
Un formato de texto para intercambiar datos entre programas, con llaves y corchetes: { "symbol": "YPF", "signal": "VENTA" }. Es lo que devuelve una API y lo que se importa en n8n.
04

Indicadores y carteras

Variación del día
Cuánto cambió el precio respecto de la rueda anterior, en %: (cierre de hoy ÷ cierre de ayer − 1) × 100.
KPI / tarjeta
Un número clave destacado arriba de la pantalla para leerlo de un vistazo: cuántos activos suben, cuál se movió más.
Sparkline
Un gráfico de línea mínimo, sin ejes, que muestra la tendencia reciente al lado de un número.
SMA media móvil simple
El promedio de los últimos N cierres, que se recalcula cada día. La SMA20 promedia 20 ruedas; la SMA50, 50. Suaviza el ruido para ver la tendencia.
EMA media móvil exponencial
Como la SMA, pero los días más recientes pesan más, así que reacciona antes a los cambios. Se usan EMA12 y EMA26.
RSI 14 índice de fuerza relativa
Un número entre 0 y 100 que compara las subas con las bajas de las últimas 14 ruedas. Arriba de 70 se suele leer como “sobrecomprado”; abajo de 30, “sobrevendido”. La versión de Wilder suaviza los promedios de una manera particular: hay que pedirla con ese nombre.
Señal
Una etiqueta que resume una regla: en FIN·LAB, COMPRA si las medias cortas están por encima de las largas, VENTA si están por debajo, NEUTRAL si no coinciden. Es didáctica, no una recomendación.
Cartera
Un conjunto de activos con un peso cada uno (por ejemplo, 30% JNJ, 25% KO…). Los pesos suman 100%.
Normalizar pesos
Reescalar los pesos para que sumen exactamente 100% sin cambiar sus proporciones.
Retorno anualizado
El rendimiento promedio diario llevado a un año (× 252). Responde “¿cuánto rindió por año, en promedio?”.
Volatilidad
Cuánto se mueve un precio alrededor de su promedio (desvío estándar), anualizada con × √252. Es la medida de riesgo más usada.
Covarianza / correlación
Miden si dos activos tienden a moverse juntos. Si no se mueven igual, combinarlos baja el riesgo: eso es diversificar.
Tasa libre de riesgo
Lo que rendiría una inversión “segura” (como un bono del Tesoro). En FIN·LAB se usa 4,3% anual.
Ratio de Sharpe
(retorno − tasa libre de riesgo) ÷ volatilidad. Cuánto rendimiento extra da la cartera por cada unidad de riesgo. Más alto es mejor.
Máxima caída drawdown
La peor baja desde un máximo hasta el mínimo siguiente. Responde “¿cuánto llegué a perder en el peor momento?”.
Base 100
Un gráfico donde todo arranca en 100 para comparar recorridos: si una cartera termina en 112, ganó 12%.
Cartera equiponderada
La que pone el mismo peso en todos los activos. Se usa como punto de comparación (benchmark).
05

APIs y servidores

API
Una “ventanilla” que entrega datos a otros programas en lugar de a personas. Le hacés un pedido a una dirección y te contesta en JSON.
Endpoint / ruta
Cada dirección concreta de una API: /api/market/summary devuelve el resumen del mercado.
HTTP / GET
HTTP es el idioma con el que se hablan los navegadores y los servidores. GET es el pedido de “dame esto” (leer, sin modificar nada).
Código de estado 200 · 404
El número con el que responde una API: 200 significa “todo bien, acá están los datos”; 404, “eso no existe”.
Router
La parte del programa que mira qué ruta te pidieron y decide qué responder.
Servidor local
Un programa que corre en tu computadora y sirve los archivos de una carpeta como si fueran un sitio web. Solo lo ves vos.
127.0.0.1 / localhost
La dirección de tu propia computadora. http://127.0.0.1:4173 significa “el sitio que sirve mi computadora en el puerto 4173”.
Puerto
Un número que distingue programas dentro de la misma computadora, como el número de departamento en un edificio. Usamos el 4173.
Terminal / línea de comandos
La ventana de texto donde se escriben órdenes (PowerShell en Windows, Terminal en Mac). Se usa una sola vez, en el paso 9, para encender el servidor local.
Vercel
Un servicio que publica sitios y APIs en internet. La API “de verdad” del proyecto vive ahí, para que n8n y Colab puedan consultarla.
06

Python y Colab

Python
El lenguaje más usado en análisis de datos. Lo usamos para recalcular los indicadores con otra herramienta y comprobar que la página no se equivocó.
Google Colab
Un sitio de Google (colab.research.google.com) donde se escribe y ejecuta Python en el navegador, sin instalar nada. Solo hace falta una cuenta de Google.
Notebook / cuaderno .ipynb
Un documento de Colab hecho de bloques de código y texto que se ejecutan de a uno.
Celda
Cada bloque de un notebook. Se ejecuta con el botón ▶ de su izquierda o con Shift + Enter.
pandas
La librería de Python para trabajar con tablas, como una planilla manejada con código. rolling(20).mean() es una SMA20 en una línea.
matplotlib
La librería clásica de Python para dibujar gráficos.
07

Automatización con n8n

n8n
Una herramienta visual para armar automatizaciones conectando cajas, sin programar (o programando poco). Se usa en la nube (n8n.io) o instalada en tu computadora.
Workflow / flujo
Una automatización completa: el conjunto de cajas conectadas que se ejecuta sola. Se puede exportar e importar como archivo JSON.
Nodo
Cada caja de un workflow. Hace una sola cosa: consultar una API, filtrar, decidir, mandar un correo.
Disparador trigger
El nodo que arranca el workflow: un botón (Manual), un horario (Schedule), un formulario, un correo que llega.
Nodo HTTP Request
El nodo que hace un pedido a una API y trae la respuesta en JSON.
Nodo Code
Un nodo donde se pega un poco de JavaScript para transformar datos (filtrar, calcular, armar un texto). La IA lo escribe por vos.
Nodo IF
Un nodo que decide: si se cumple la condición, sigue por la salida true; si no, por la false.
Credencial
La contraseña o permiso para que n8n use tu correo o tu Telegram. Se carga aparte, en el menú de credenciales: nunca se escribe dentro de un nodo.
Importar workflow
Cargar en n8n un archivo JSON con un flujo ya armado: menú ⋯ → Import from File.
