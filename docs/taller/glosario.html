Glosario del taller

Trabajar con IA

Prompt
El texto con el que le pedís algo a la IA. Cuanto más claro digas qué querés, con qué datos y en qué formato, mejor sale la respuesta.
Prompt de contexto
Un prompt que se pega una sola vez al principio del chat y fija las reglas de todo el proyecto (un solo archivo, datos simulados, español…). Es como la consigna general de un trabajo práctico.
Chat de IA ChatGPT, Claude, Gemini
La ventana donde conversás con el modelo. Recuerda lo que se dijo en ese chat, pero no en otros: si abrís uno nuevo, hay que volver a darle el contexto y el archivo.
Alucinación
Cuando la IA inventa un dato con total seguridad. Por eso cada paso tiene una comprobación hecha por una persona.
Versión
Una copia guardada del archivo en un momento en que funcionaba (finlab-v3.html). Si un cambio rompe todo, se vuelve a la última versión buena.

La página web

HTML .html
El tipo de archivo de las páginas web. Todo el taller produce uno solo: finlab.html.
Consola del navegador F12
El panel oculto donde aparecen los errores del código. Se abre con F12, pestaña Console. Si la página queda en blanco, la respuesta casi siempre está ahí, en rojo.
Pestaña
Cada sección de la terminal (Mercado, Carteras…). Al hacer clic se muestra solo esa parte.

Datos y archivos

Datos simulados
Números generados por una fórmula que imitan un precio. No son cotizaciones reales; sirven para que todos vean lo mismo.
Semilla seed
El número de arranque de un generador de “azar”. Con la misma semilla salen siempre los mismos números.
Rueda
Un día hábil de mercado. Un año tiene unas 252.
Ticker / símbolo
El código corto de un activo: AAPL (Apple), GGAL (Galicia), YPF.
CSV .csv
Una tabla guardada como texto, con valores separados por comas. Se abre con Excel o Google Sheets.
JSON
Un formato de texto para intercambiar datos entre programas, con llaves y corchetes. Es lo que devuelve una API y lo que se importa en n8n.

Indicadores y carteras

Variación del día
Cuánto cambió el precio respecto de la rueda anterior, en %: (cierre de hoy ÷ cierre de ayer − 1) × 100.
Sparkline
Un gráfico de línea mínimo, sin ejes, al lado de un número.
SMA / EMA media móvil
Promedio de los últimos N cierres (SMA 20 = 20 ruedas). La EMA da más peso a los días recientes y reacciona antes.
RSI 14 índice de fuerza relativa
De 0 a 100: mide si el precio subió más de lo que bajó. Arriba de 70, subió mucho; abajo de 30, bajó mucho.
Señal
Una etiqueta que resume una regla: COMPRA si las medias cortas están sobre las largas, VENTA si están debajo, NEUTRAL si no coinciden. Didáctica, no una recomendación.
Normalizar pesos
Reescalar los pesos para que sumen exactamente 100% sin cambiar sus proporciones.
Volatilidad
Cuánto suele subir o bajar un precio en un día, llevado al año (desvío estándar × √252). Es la medida de riesgo más usada.
Covarianza / correlación
Miden si dos activos se mueven juntos; la correlación va de −1 (al revés) a +1 (igual). Si uno sube cuando el otro baja, se compensan: eso es diversificar.
Tasa libre de riesgo
Lo que rendiría una inversión “segura”. En FIN·LAB, 4,3 % anual.
Ratio de Sharpe
Cuánto se gana de más sobre la tasa segura, por cada punto de riesgo: (retorno − tasa libre) ÷ volatilidad. Más alto es mejor.
Anualizar retorno · volatilidad
Llevar un número diario a un año: el retorno se multiplica por 252 y la volatilidad (desvío estándar diario) por √252 ≈ 15,9. Ejemplo: desvío diario de 1,5 % × 15,9 ≈ 23,9 % anual.
Backtest
Probar una regla con precios pasados, como si se hubiera usado entonces.
Sesgo de anticipación mirar el futuro
Decidir con datos del futuro. Ejemplo: comprar ayer porque hoy el precio subió.
Comprar y mantener
Comprar el primer día y no tocar nada hasta el final.
Máxima caída drawdown
La peor baja desde un máximo hasta el mínimo siguiente. Ejemplo: de 120 a 90 es −25 %.
Base 100
Gráfico donde todo arranca en 100: si una cartera termina en 112, ganó 12 %.
Cartera equiponderada
La que pone el mismo peso en todos los activos. Se usa como punto de comparación (benchmark).

APIs y servidores

API
Una “ventanilla” que entrega datos a otros programas en lugar de a personas. Le hacés un pedido a una dirección y te contesta en JSON.
Servidor local 127.0.0.1
Un programa de tu computadora que muestra una carpeta como si fuera un sitio web, solo para vos. 127.0.0.1 es tu propia computadora y 4173, el puerto (el “número de departamento”). Se enciende desde la terminal, la ventana de texto (PowerShell en Windows).
Vercel
Servicio que publica la API del proyecto en internet, para que n8n y Colab la consulten.

Python y Colab

Google Colab
Un sitio de Google donde se ejecuta Python (el lenguaje del análisis de datos) en el navegador, sin instalar nada. Solo hace falta una cuenta de Google.
Notebook / cuaderno .ipynb
Un documento de Colab hecho de bloques de código y texto que se ejecutan de a uno.
Celda
Cada bloque de un notebook. Se ejecuta con ▶ o con Shift + Enter.

Automatización con n8n

n8n
Una herramienta visual para armar automatizaciones conectando cajas. Se usa en la nube (n8n.io) o instalada en tu computadora.
Workflow / flujo
Una automatización completa: cajas conectadas que se ejecutan solas. Se exporta e importa como archivo JSON (menú ⋯ → Import from File).
Nodo
Cada caja de un workflow. Hace una sola cosa: consultar una API, filtrar, decidir, mandar un correo.
Disparador trigger
El nodo que arranca el workflow: un botón (Manual), un horario (Schedule), un correo que llega.
Nodo HTTP Request
El nodo que le hace un pedido a una API (GET = “dame esto”, sin modificar nada) y trae la respuesta en JSON.
Nodo Code
Un nodo con un poco de JavaScript para calcular o armar un texto. La IA lo escribe por vos.
Nodo IF
Un nodo que decide: si se cumple la condición sigue por true; si no, por false.
Credencial
La caja fuerte de n8n: el flujo usa la llave (contraseña, clave de API o token de acceso) sin verla. Nunca se escribe dentro de un nodo.

Agentes, modelos y claves

Clave de API API key
La contraseña larga que identifica tu cuenta cuando un programa usa un servicio. Nunca va dentro de una página web: cualquiera que abra el archivo la vería.
Modelo LLM
El programa de IA que recibe un texto y devuelve otro. Conviene uno chico y rápido para clasificar y uno grande para razonar.
Token
La unidad con que se mide y se cobra el texto de un modelo: unas 4 letras. El precio es por millón de tokens, y cada vuelta de un agente vuelve a mandar la conversación.
Prompt de sistema system
La instrucción fija que define el papel del modelo antes de la pregunta: “sos un analista que no da recomendaciones de inversión”. En n8n es el campo System Message.
Agente
Una IA que elige sola qué herramienta usar y cuándo parar. Un workflow sigue un mapa; un agente elige el camino.
Traza
El diario de lo que hizo un agente: qué herramienta, en qué orden y con qué resultado.
Tope de pasos
Cuántas vueltas puede dar el agente antes de tener que contestar.
Herramienta tool
Una acción que el agente puede pedir: consultar una API, hacer una cuenta, buscar en la web.
Consejo de agentes
Varios agentes con roles distintos que se revisan entre sí: uno redacta, otro audita los números, otro controla el tono.
MCP Model Context Protocol
Un enchufe estándar para que el asistente maneje n8n con permisos, sin copiar y pegar el JSON.
Límite de uso rate limit
El máximo de pedidos por minuto que acepta un servicio. Si te pasás, error 429: esperá o pedí menos.
