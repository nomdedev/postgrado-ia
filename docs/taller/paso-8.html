PASO 8 · EL ANÁLISIS SALE SOLO

Un workflow de n8n que avisa cuando hay algo para mirar

La última capa sale del navegador. Un workflow de n8n consulta la API todos los días, filtra los activos que cumplen una condición y avisa solo si encontró algo. No lo arman de cero: importan uno ya hecho y lo adaptan con IA.

20 MINN8NSALIDA: WORKFLOW FUNCIONANDO
  1. Importen el workflowun archivo que se descarga con un botón
  2. Adáptenlo con IAcon el prompt listo para copiar
  3. Ejecútenloy cuenten a mano los avisos

Tranquilos: no hace falta entender el código. Todo lo que hay que llevar a otro lado tiene un botón ⧉ COPIAR. Los textos largos están plegados y se abren con VER EL TEXTO solo si les da curiosidad.

01

Qué van a lograr

Un workflow importado en n8n que, al ejecutarlo, muestra qué activos tienen señal de VENTA o un RSI fuera del rango 30–70, con el motivo de cada aviso:

RESULTADO ESPERADO · SALIDA DEL NODO “ARMAR AVISO”
Asunto: FIN·LAB · 2 activos para mirar

- YPF: 26.33 USD · RSI 41.7 · señal VENTA → motivo: señal de venta
- GGAL: 28.75 USD · RSI 72.4 · señal NEUTRAL → motivo: RSI mayor a 70

Muestra educativa fija de FIN·LAB. No es una recomendación de inversión.
Importante: n8n no puede consultar la API que armaron en el paso 6, porque esa vive dentro de su navegador. Usa la API publicada del proyecto (https://…vercel.app/api/market/summary), que devuelve los mismos campos. El docente les pasa la URL.
02

El flujo: los nodos del workflow

Disparador → pasos → una de dos salidas.ABRIR EN PANTALLA COMPLETA ↗
  • Manual o Schedule · El disparador. Para probar usan el botón Execute workflow; después se puede programar todos los días a las 18:00.
  • HTTP Request · Hace un GET a la API y recibe el JSON con los ocho activos.
  • Code · Unas líneas de JavaScript (las escribe la IA) que se quedan con los activos que cumplen la condición y arman el texto.
  • IF · ¿Quedó alguno? Si sí → Email o Telegram con el aviso. Si no → Registrar que no hubo novedades, sin mandar nada.

04

Qué hacer, clic por clic

A · Tener n8n abierto (elijan una opción)

  1. En la nube (más simple): creen una cuenta de prueba en n8n.io y entren a su espacio de trabajo.
  2. En la computadora (si tienen Node.js): abran PowerShell y escriban npx n8n. Cuando diga Editor is now accessible, abran http://localhost:5678 en el navegador.

B · Importar y adaptar el workflow

  1. Descarguen aviso-senal.json con el botón de abajo.
  2. En n8n: Create workflow → menú ⋯ (arriba a la derecha) → Import from File… → elijan el archivo. Aparecen las cajas conectadas.
  3. Abran el JSON con el Bloc de notas, cópienlo y péguenlo en el chat de IA debajo del prompt de la sección 05.
  4. Guarden la respuesta como aviso-rsi.json e impórtenla igual que el anterior.
  5. Doble clic en el nodo HTTP Request y reemplacen https://TU-PROYECTO.vercel.app por la URL del curso.
  6. Toquen Execute workflow (abajo, al centro). Cada nodo que funciona se pone verde; hagan clic en cada uno para ver qué recibió y qué entregó.
  7. El correo, al final: si quieren que llegue de verdad, abran el nodo de email → Credential → Create new y sigan los pasos. Si no, alcanza con ver la salida del nodo anterior.

06

Cómo comprobar

  • Importa sin errores y todas las cajas están conectadas.
  • Cuenta a mano: abran la URL de la API en el navegador y cuenten cuántos activos tienen señal VENTA o RSI fuera de 30–70. Tiene que coincidir con la cantidad de avisos.
  • Caso vacío: cambien en el nodo Code el umbral de 70 a 99 y el de 30 a 1, y quiten la condición de VENTA. Al ejecutar, tiene que salir por la rama no y no enviar nada.
  • Sin claves a la vista: ningún nodo tiene contraseñas escritas.
07

Si algo falla

  • “Could not find property option” o un nodo en rojo al importar: la IA usó una versión de nodo distinta. Copien el mensaje de error y pídanle: “n8n muestra este error al importar: [error]. Corregí solo ese nodo.”
  • El nodo HTTP falla con ENOTFOUND o 404: la URL quedó con TU-PROYECTO o le falta /api/market/summary.
  • Funciona, pero manda un correo vacío: el IF está mirando el campo equivocado. Abran el nodo Code, miren cómo se llama el campo que indica si hay avisos y usen ese en el IF.
