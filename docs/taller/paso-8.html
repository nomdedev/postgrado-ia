PASO 8 · N8N

Un workflow de n8n que avisa cuando hay algo para mirar

Importan un workflow hecho y lo adaptan con IA.

30–40 MINSALIDA: WORKFLOW FUNCIONANDOIA · NIVEL 4 DE 5
Una idea nueva: n8n ejecuta solo un workflow: consulta, decide y avisa. Ejemplo: si JNJ tiene RSI 28,1 y señal de VENTA, manda el aviso.

Qué van a lograr

Al ejecutar el workflow, el nodo Filtrar avisos muestra los activos con señal VENTA o con RSI fuera de 30–70 (menos de 30, bajó mucho; más de 70, subió mucho):

RESULTADO ESPERADO · NODO “FILTRAR AVISOS”
Asunto: FIN·LAB · 2 activos para mirar

- JNJ: 117.88 USD · RSI 28.1 · señal VENTA → motivo: señal de venta y RSI menor a 30
- KO: 66.09 USD · RSI 70.7 · señal COMPRA → motivo: RSI mayor a 70

Muestra educativa fija de FIN·LAB. No es una recomendación de inversión.

Qué hacer, clic por clic

DESCARGAR AVISO-SENAL.JSON

  1. Abran n8n: cuenta de prueba en n8n.io (la primera vez pide crear un usuario) o, con Node.js, npx n8n y http://localhost:5678. Importen el archivo: Create workflow → ⋯ → Import from File…. Tiene que verse una cadena de cajas conectadas.
  2. Adáptenlo con IA: abran el .json con el Bloc de notas, copien todo y péguenlo al final del prompt. Guarden la respuesta como aviso-rsi.json e impórtenla igual.
  3. Ejecútenlo. En HTTP Request, la URL tiene que ser https://postgrado-ia.vercel.app/api/market/summary (n8n no ve la API del paso 6). Toquen Execute workflow: los nodos se ponen verdes y Filtrar avisos muestra 2 avisos. El nodo de correo se pone rojo sin credencial: es normal.

El prompt

PROMPT · ADAPTAR EL WORKFLOW
Paso 8. Te paso un workflow de n8n (JSON) que consulta GET /api/market/summary, filtra los activos con señal VENTA y manda un correo.

Quiero adaptarlo así:
- que avise también cuando el RSI 14 de un activo sea mayor a 70 o menor a 30
- que el mensaje diga, por activo: símbolo, precio, RSI, señal y el motivo del aviso
- que si no hay nada para avisar, no mande nada
- que los umbrales y la señal queden en constantes al principio del nodo Code (const RSI_ALTO = 70, const RSI_BAJO = 30, const SENAL = 'VENTA'), para poder cambiarlos sin tocar el resto

Devolveme el JSON completo listo para importar y una tabla con cada nodo: nombre, qué recibe y qué entrega. No inventes nodos que no existan en n8n y no pongas contraseñas ni claves dentro de los nodos.

[pegar acá el contenido de aviso-senal.json]

Cómo comprobar

  • Importa sin errores y todas las cajas están conectadas.
  • Cuenta a mano: en la API, los activos con VENTA o con RSI fuera de 30–70 son los avisos: JNJ y KO.
  • Caso vacío: en el nodo Code, pongan RSI_ALTO en 99, RSI_BAJO en 1 y SENAL en 'NINGUNA'. Tiene que salir por la rama false y no enviar nada.
  • Sin claves a la vista: ningún nodo tiene contraseñas escritas.

Si algo falla

¿Trabados tras tres intentos? Importen el workflow ya hecho: avisa JNJ y KO, con arranque manual y el correo desactivado. ⬇ BAJAR EL RESCATE ¿Sin internet? Esta versión trae la muestra adentro. ⬇ VERSIÓN SIN INTERNET
  • “Could not find property option” al importar: pídanle a la IA “n8n muestra este error: [error]. Corregí solo ese nodo.”
  • ENOTFOUND o 404: la URL está mal escrita o no termina en /api/market/summary.
  • Correo vacío: el IF mira otro campo; usen el que arma el nodo Code.
