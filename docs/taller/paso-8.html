    Un workflow de n8n que avisa cuando hay algo para mirar

    La última capa sale del navegador. Un workflow de n8n consulta la API todos los días, filtra los activos que cumplen una condición y avisa solo si encontró algo. No lo arman de cero: importan uno ya hecho y lo adaptan con IA.

    20 MINN8NSALIDA: WORKFLOW FUNCIONANDO

    Qué van a lograr

    Un workflow importado en n8n que, al ejecutarlo, muestra qué activos tienen señal de VENTA o un RSI fuera del rango 30–70, con el motivo de cada aviso:

    RESULTADO ESPERADO · SALIDA DEL NODO “ARMAR AVISO”CON LA MUESTRA FIJA DE LA API
    Asunto: FIN·LAB · 2 activos para mirar

- JNJ: 117.88 USD · RSI 28.1 · señal VENTA → motivo: señal de venta y RSI menor a 30
- KO: 66.09 USD · RSI 70.7 · señal COMPRA → motivo: RSI mayor a 70

Muestra educativa fija de FIN·LAB. No es una recomendación de inversión.
    Importante: n8n no puede consultar la API que armaron en el paso 6, porque esa vive dentro de su navegador. Usa la API publicada del proyecto (https://postgrado-ia.vercel.app/api/market/summary), que devuelve el mismo formato que la API que armaron en el paso 6.

    Qué hacer, clic por clic

    A · Tener n8n abierto (elijan una opción)

    1. En la nube (más simple): creen una cuenta de prueba en n8n.io y entren a su espacio de trabajo.
    2. En la computadora (si tienen Node.js): abran PowerShell y escriban npx n8n. Cuando diga Editor is now accessible, abran http://localhost:5678 en el navegador.

    B · Importar y adaptar el workflow

    1. Descarguen aviso-senal.json con el botón de abajo.
    2. En n8n: Create workflow → menú ⋯ (arriba a la derecha) → Import from File… → elijan el archivo. Aparecen las cajas conectadas.
    3. Abran el JSON con el Bloc de notas, cópienlo y péguenlo en el chat de IA debajo del primer prompt de “Los prompts”, más abajo.
    4. Guarden la respuesta como aviso-rsi.json e impórtenla igual que el anterior.
    5. Doble clic en el nodo HTTP Request y confirmen que la URL sea la del curso: https://postgrado-ia.vercel.app/api/market/summary. Si la IA la cambió, péguenla de nuevo.
    6. Toquen Execute workflow (abajo, al centro). Cada nodo que funciona se pone verde; hagan clic en cada uno para ver qué recibió y qué entregó.
    7. El correo, al final: si quieren que llegue de verdad, abran el nodo de email → Credential → Create new y sigan los pasos. Si no, alcanza con ver la salida del nodo anterior. Si crean una credencial en una computadora o cuenta compartida, bórrenla al terminar (Credentials → ⋯ → Delete).

    Cómo comprobar

    • Importa sin errores y todas las cajas están conectadas.
    • Cuenta a mano: abran la URL de la API en el navegador y cuenten cuántos activos tienen señal VENTA o RSI fuera de 30–70. Tiene que coincidir con la cantidad de avisos y con los activos (con la muestra fija del curso: JNJ y KO).
    • Caso vacío: abran el nodo Code y, en las primeras líneas, cambien RSI_ALTO a 99, RSI_BAJO a 1 y SENAL a 'NINGUNA'. Al ejecutar, tiene que salir por la rama no y no enviar nada.
    • Sin claves a la vista: ningún nodo tiene contraseñas escritas.

    Si algo falla

    ¿Se trabaron después de tres intentos? Este workflow ya cumple todo lo del paso: avisa por señal VENTA o RSI fuera de 30–70 y explica el motivo. Impórtenlo igual que el otro y toquen Execute workflow; tiene que avisar JNJ y KO. El nodo de correo viene desactivado para que funcione sin credenciales. ⬇ BAJAR EL WORKFLOW DE RESCATE
    ¿No hay internet o la URL no responde? Usen la versión sin internet: en lugar de consultar la API trae adentro la misma muestra fija, así pueden practicar todo el recorrido igual. ⬇ BAJAR LA VERSIÓN SIN INTERNET
    • “Could not find property option” o un nodo en rojo al importar: la IA usó una versión de nodo distinta. Copien el mensaje de error y pídanle: “n8n muestra este error al importar: [error]. Corregí solo ese nodo.”
    • El nodo HTTP falla con ENOTFOUND o 404: la URL está mal escrita o le falta /api/market/summary.
    • Funciona, pero manda un correo vacío: el IF está mirando el campo equivocado. Abran el nodo Code, miren cómo se llama el campo que indica si hay avisos y usen ese en el IF.
