    • PASO 14 · DEL CHAT AL FLUJO, SIN COPIAR Y PEGAR

    El MCP de n8n: crear workflows desde el chat

    Hasta acá el asistente opinaba sobre el flujo y ustedes copiaban el JSON a mano. Con el MCP de n8n, el asistente puede listar, leer y crear workflows directamente. Es el mismo nodo de siempre, con una herramienta nueva en la mano.

    20 MINN8NUN ASISTENTE CON MCPSALIDA: UN FLUJO CREADO DESDE EL CHAT
    ¿El asistente que usan no soporta MCP? El paso se puede ver en la demostración del docente. Lo importante es entender qué cambia: el asistente deja de proponer texto y pasa a ejecutar acciones con permisos.

    Qué van a lograr

    El servidor MCP de n8n conectado a su asistente, y un workflow creado desde el chat que después abren en n8n para comprobar que existe, que tiene los nodos pedidos y que quedó desactivado hasta que lo revisen.

    PEDIDO EN EL CHATLO QUE HACE EL MCPQUÉ SE VE EN N8N
    “listá mis workflows”lee la listalos mismos nombres de siempre
    “copiá el del RSI y cambiá el umbral a 25”lee uno y crea otroun workflow nuevo, desactivado
    “probalo con los datos de hoy”ejecuta la pruebala corrida queda en el historial
    El MCP no reemplaza la revisión: crea y prueba. Activar un flujo con datos reales sigue siendo una decisión humana.

    El prompt

    PROMPT · PASO 14
    Para el asistente conectado al MCP de n8n.
    Estoy conectado al MCP de n8n. Antes de tocar nada:

1. listá mis workflows y decime cuál corresponde al aviso por RSI
2. leelo y resumí en 3 líneas qué hace y qué credenciales usa
3. creá una copia llamada "aviso-rsi-umbral-25" que cambie el umbral de RSI de 30 a 25, sin activarla
4. mostrame el JSON de la copia y esperá mi confirmación antes de ejecutarla
5. si algo falla, no borres ni sobrescribas el original: decime qué falló

No actives ningún workflow ni cambies credenciales sin que te lo pida explícitamente.
    Puente con el proyecto real: este taller se armó con un asistente que usa herramientas (archivos, tests, navegador) y pide permiso antes de actuar. El MCP de n8n aplica la misma idea a sus workflows. El diagrama “Así se hizo este taller” muestra ese circuito.

    Qué hacer, clic por clic

    1. Activen el servidor MCP en su instancia de n8n : Settings → Instance-level MCP → Enable MCP access. Si no aparece, la versión de n8n es anterior: pidan al docente que la actualice.
    2. Copien la dirección (termina en /mcp-server/http) y el token que muestra n8n. El token es una clave: va en la configuración del asistente, no en el chat.
    3. Agreguen el servidor MCP en su asistente (Claude, ChatGPT o el que usen) con esa dirección y ese token. En Claude Code es una sola línea; cambien el dominio por el de su n8n:
      TERMINAL · CLAUDE CODE
      Después les pide iniciar sesión en n8n.
      claude mcp add --transport http n8n https://SU-DOMINIO/mcp-server/http
    4. Pidan la lista de workflows y compárenla con la que ven en n8n.
    5. Pidan la copia con el umbral cambiado y revisen el JSON antes de ejecutar.
    6. Abran n8n, comprueben que la copia existe y que está desactivada. Prueben y después decidan si la activan.
    7. Borren la copia de prueba y revoquen el token si era uno temporal.

    Cómo comprobar

    • El flujo existe: la copia aparece en n8n con el nombre que pidieron y los nodos del original.
    • El cambio es el pedido: el umbral quedó en 25 y el resto del flujo no cambió.
    • Nada se activó solo: la copia está desactivada y el original sigue igual.
    • El token no quedó en el chat: se cargó en la configuración del asistente, no en un mensaje.

    Si algo falla

    ¿Se trabaron después de tres intentos? El MCP depende de la versión de n8n y del asistente. Si no conecta, prueben con el asistente del docente y sigan el paso mirando la pantalla.
    • “No se puede conectar”: la instancia no es accesible desde internet o la dirección está incompleta. Prueben primero en local.
    • “Sin permiso”: el token no tiene el alcance necesario, o se revocó. Generen uno nuevo y vuelvan a cargarlo en el asistente.
    • Su n8n no tiene la opción MCP: existe un servidor comunitario (n8n-mcp, código abierto) que usa la API de n8n con una clave propia. Ojo: la prueba gratis de n8n Cloud no incluye la API.
    • El asistente no ve las herramientas: hay que reiniciar la conversación después de agregar el servidor MCP.
    • Creó el flujo dos veces: pasa cuando se reintenta el pedido. Revisen la lista y borren el duplicado.
