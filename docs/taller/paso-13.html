El consejo de agentes: que el desacuerdo se vea

Un consejo de agentes: uno analiza, otro audita y otro redacta.

30 MINN8NIA · NIVEL 5 DE 5
Una idea nueva: El auditor busca lo que el analista no dijo. Ejemplo: el analista dice “mantener”; el auditor marca que JNJ tiene señal de VENTA.

Qué van a lograr

Un informe con el reparo del auditor a la vista, armado por tres agentes encadenados en n8n.

El prompt

PROMPT · PASO 13
Paso 13 de un taller de finanzas con n8n. Tengo un agente que consulta la API del curso y hace cuentas con una calculadora.

Quiero armar un consejo de tres agentes encadenados: analista → auditor → redactor.

Para cada rol escribime el prompt de sistema, con estas condiciones:
- el analista propone una cartera y muestra los números que usó
- el auditor busca el error, el dato faltante y el supuesto no dicho; no puede proponer otra cartera
- el redactor escribe 5 líneas para un cliente, incluye el reparo del auditor y no da recomendaciones de inversión
- si el auditor no encuentra nada, tiene que decirlo explícitamente y explicar qué revisó

Después decime qué pregunta de prueba hace visible la diferencia entre un solo agente y el consejo.
Ejemplo resuelto: la traza del comité.

Qué hacer

  1. Copien tres veces el agente del paso 12, con su modelo y sus herramientas: analista, auditor y redactor. El analista y el auditor llevan la API; el redactor no necesita herramientas.
  2. Peguen en cada uno su prompt de sistema (el que dio la IA) en el campo System Message.
  3. Encadénenlos: en el auditor, Prompt = Define below y arrastren ahí el campo output del analista; el redactor recibe el de los dos.
  4. Abran Open chat y pregunten: “Tengo 40 % KO, 30 % JNJ y 30 % GGAL: ¿qué reparos hay antes de mantenerla hoy?”. Miren el Output de cada nodo: ahí se ve el desacuerdo.

Cómo comprobar

  • El auditor agrega algo: el informe menciona un supuesto o un dato faltante.
  • Los números son de la API: KO 66,09 · JNJ 117,88 · GGAL 28,75 y la cartera +0,56 % (0,4 × 0,82 + 0,3 × 0,25 + 0,3 × 0,52).
  • No recomienda: no dice “comprá” ni “vendé”.
  • Mejora al paso 12: con la misma pregunta. Si no, el consejo sobra.

Si algo falla

  • Los tres dicen lo mismo: tienen el mismo prompt. Pídanle al auditor que busque el error.
  • El informe ignora al auditor: el redactor no recibe su salida.
  • El auditor inventa: que cite el dato exacto; si no puede, no cuenta.
  • No les corre ningún agente: importen agente-api.json, el rescate del paso 12.
